# Invoice Tracking and Escalation Workflow

A Make.com automation blueprint for tracking invoices and escalating overdue ones, designed as a take-home assignment for a fintech AI-operations role.

## Goal

Replace manual invoice chasing with a workflow that tracks invoice status and escalates automatically when follow-up is needed.

## Scope

This repository documents the workflow design (a blueprint). It is an assignment submission, not a production deployment.

## Stack

Make.com
